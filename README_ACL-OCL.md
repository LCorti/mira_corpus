# README ACL-OCL

[![License](https://img.shields.io/badge/License-CC%20BY--NC%204.0-lightgrey.svg)](https://creativecommons.org/licenses/by-nc-sa/4.0/)

Here you can find most of the data from [ACL-OCL](https://github.com/shauryr/ACL-anthology-corpus/tree/main).

The goal here is to have a simple collection of scientific papers in plain text for testing machine summarisation with LLMs.

Please refer to the original repository ([https://github.com/shauryr/ACL-anthology-corpus/](https://github.com/shauryr/ACL-anthology-corpus/)) for all the details and the original contents (incl. revisions).
